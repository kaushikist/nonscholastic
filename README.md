# Nonscholastic 🎨
A platform connecting learners with non-scholastic courses, activities, and instructors near them.

---

## 📌 Features & Screen Workflow

1. **Onboarding & Auth**
   - Welcoming splash screen & doodle-style authentication.
   - Interactive interest picker (*Performing Arts, Music, Sports, Crafts*).

2. **Explore & Discover**
   - **New & Popular** spotlight section.
   - **Popular Near You** localized course finder.
   - Tabbed Navigation: `Home` | `Map` | `Explore` | `Profile`.

3. **Courses & Classes**
   - Detailed course breakdown (*Difficulty, Duration, Fees, Ratings*).
   - Instructor dashboard to add, edit, or delete listings.

4. **User & Instructor Profiles**
   - View profile stats, active schedules, course reviews, and upcoming lectures.

---

## 🎨 Design Guidelines & Aesthetics

* **Theme**: Playful scrapbook / paper notebook aesthetics.
* **Texture**: Crumpled paper backgrounds, paperclip accents, doodle borders, cutout star buttons.
* **Assets**: All stickers, custom backgrounds, and icons must be placed in `/assets`.

## 🚀 Getting Started

### Prerequisites
* Node.js (v18+)
* Package manager: `npm` or `yarn`

### Installation
```bash
# Clone the repository
git clone [https://github.com/your-org/nonscholastic.git](https://github.com/your-org/nonscholastic.git)

# Navigate into the project
cd nonscholastic

# Install dependencies
npm install

# Start the development server
npm start
